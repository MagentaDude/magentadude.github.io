Metadata Specification

MDA uses the MessagePack format to store audio metadata. MessagePack has similar functionality to JSON, making it extremely flexible, and it also has the benefit of being able to efficiently store data, including binary, making it ideal for embedding album covers.

MDA's format uses a 24-bit unsigned integer to store the length of the metadata, with a maximum of 16,777,215 bytes (almost 17 MB). This was chosen because large amounts of metadata should not be embedded in the format, and a 16-bit range would be too low for most images. However, the length of the actual audio data stored in an MDA file is theoretically limitless.

All metadata keys should be in camelCase. Below is a list of official metadata keys, heavily based off of the metadata fields seen in foobar2000. All keys are optional, and you can include your own custom keys as well.

{
  "artist": str,
  "title": str,
  "album": str,
  "date": {
    "d": int, // day of the month
    "m": int, // month number
    "y": int, // year
  },
  "genre": str,
  "composer": str,
  "performer": str,
  "albumArtist": str,
  "trackNumber": int,
  "totalTracks": int,
  "discNumber": int,
  "totalDiscs": int,
  "comment": str,
  "copyright": str,
  "license": str,
  "contact": str,
  "cover": bin // image data
}
