MagentaDude Audio, or MDA for short, is a simple lossy audio format optimized for pleasant quality, 1 bit per sample compression (64kbps @ 32khz stereo), and blazing-fast encoding and decoding.

Q&A

How does MDA compare to [insert audio format here]?

Format Transparent bitrate* Typical artifacts Speed
MP3 192kbps Metallic noises, pre-echo Medium
OGG 128kbps Swooshing, pre-echo Slow
Opus 64kbps Crackling Fast
QOA 201kbps** White noise Very fast
MDA 64kbps** White noise Very fast
* In my opinion; very subjective!
** Fixed bits per sample format; I've used 32khz stereo as a reference point

As you can see, it's like Opus but faster and with more white noise. If you want to listen for yourself, you can try out the audio samples.

What if I don't want any artifacts at all?

For that you would want a lossless audio format. I recommend the excellent and widely supported FLAC format, which typically cuts the size of an uncompressed WAV file in half while still preserving all audio data.
